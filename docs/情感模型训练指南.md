# 情感分析模型训练 - 使用指南

## 📋 什么是情感分析？

情感分析模型可以自动判断玩家评论是**正面**、**中性**还是**负面**，帮助您快速了解玩家对游戏更新的整体反应。

**示例：**
- ✅ **正面**: "这次更新太棒了！新地图非常有趣"
- ➖ **中性**: "更新了UI界面，还在适应中"
- ❌ **负面**: "匹配系统更新后变得很糟糕"

---

## 🎯 训练目的

训练两个情感分析模型，对比性能：

| 模型 | 技术 | 预期准确率 | 速度 |
|------|------|-----------|------|
| **基础版** (Baseline) | 传统机器学习 | 82-83% | 快速 ⚡ |
| **进阶版** (BERT) | 深度学习 | 85-87% | 较慢 🐌 |

**为什么训练两个？**
- 基础版：快速部署，适合实时分析
- 进阶版：更准确，适合重要更新的深度分析

---

## 📊 训练数据

- **数据量**: 176,000 条玩家评论
- **游戏类型**: FPS游戏（如《Rust》《CS:GO》）
- **类别分布**:
  - 正面评论：~40%
  - 中性评论：~35%
  - 负面评论：~25%

---

## ⏱️ 训练时间

**预计时长**: 5-6 小时

**训练过程**:
- Fold 1/5: ~1 小时
- Fold 2/5: ~1 小时
- Fold 3/5: ~1 小时
- Fold 4/5: ~1 小时
- Fold 5/5: ~1 小时

**什么是 Fold？**  
为了确保模型稳定性，我们将数据分成5份，轮流训练和测试。这样可以得到更可靠的性能评估。

### 方法1：直接运行（推荐）
```bash
python train_sentiment_bert_fps.py
```

## 📈 如何查看进度

训练过程中，终端会显示：

```
================================================================================
FOLD 1/5
────────────────────────────────────────────────────────────────────────────────
Train: 141,000 samples [24.8%, 35.2%, 40.0%]
Test:  35,000 samples [25.1%, 35.0%, 39.9%]

[Fold 1] Training Baseline (TF-IDF + LR on processed text)...
  → Acc: 0.8245, W-F1: 0.8201, M-F1: 0.8156
  → Per-class F1: Neg=0.7892, Neu=0.8123, Pos=0.8453

[Fold 1] Training BERT (DistilBERT on clean text)...
  Epoch 1/5 - Loss: 0.4521
  Epoch 2/5 - Loss: 0.3214
  ...
  → Acc: 0.8567, W-F1: 0.8523, M-F1: 0.8489
```

**指标解释**:
- **Acc (准确率)**: 整体判断正确的比例（越高越好）
- **W-F1 (加权F1)**: 综合考虑各类别的性能（主要指标）
- **M-F1 (宏F1)**: 各类别平均性能
- **Per-class F1**: 每个类别的性能
  - Neg: 负面评论识别准确度
  - Neu: 中性评论识别准确度
  - Pos: 正面评论识别准确度

**关键指标**:

| 指标 | 基础版 | 进阶版 | 说明 |
|------|--------|--------|------|
| **准确率** | 82.45% | 85.67% | 整体正确率提升 **3.22%** |

## ✅ 成功标准

训练成功的标志：

- ✅ **基础版准确率** ≥ 82%
- ✅ **进阶版准确率** ≥ 85%
- ✅ **性能提升** ≥ 2%
- ✅ **各类别F1** ≥ 0.75（没有明显短板）
- ✅ **5折标准差** < 0.01（稳定性良好）

**如果未达标怎么办？**
1. 检查数据质量（是否有大量噪声）
2. 调整训练参数（联系技术团队）
3. 增加训练时间（增加 epoch）

## 🔍 常见问题

### Q1: 训练中断了怎么办？
**A:** 需要重新训练。建议使用后台运行方式避免意外中断。

### Q2: 内存不足报错
**A:** 降低批次大小（修改 `BATCH_SIZE = 16` 改为 `8`），训练时间会增加。

### Q3: GPU未被使用
**A:** 检查是否安装CUDA。如果没有GPU，会自动使用CPU（速度较慢，约8-10小时）。

### Q4: 如何使用训练好的模型？
**A:** 模型训练完成后，可以用于推理系统：
```bash
python batch_inference.py --genre fps --update_date 2024-03-20
```

### Q5: 两个模型如何选择？
**A:** 
- **实时监控**：用基础版（快速）
- **重要更新分析**：用进阶版（准确）
- **大规模分析**：用基础版（成本低）
