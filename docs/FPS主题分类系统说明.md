# FPS游戏主题分类系统说明

## 📋 什么是这个系统？

这是一个智能系统，可以自动分析玩家对FPS游戏的评论，并识别出评论中提到的问题类型。

## 🎯 系统能做什么？

系统可以识别6种主要的游戏问题类型：

1. **匹配问题 (matchmaking_issues)** - 游戏匹配、排位、服务器连接等问题 (~26%)
2. **多人游戏功能 (multiplayer_features)** - 一般多人游戏体验反馈 (~21%)
3. **作弊问题 (cheating)** - 外挂、作弊者、反作弊系统 (~20%)
4. **用户界面 (user_interface)** - 游戏界面、画面、性能表现 (~15%)
5. **技术问题 (technical_issues)** - 崩溃、错误、更新问题 (~12%)
6. ** monetization_concerns)** - 付费、赌博、游戏内购买 (~5%)

## 🔧 技术实现

系统使用两种方法进行分析：

### 方法1: 基础方法 (TF-IDF + 逻辑回归)
- **原理**: 统计评论中出现的重要词语
- **优势**: 运行速度快，资源占用少
- **预期准确率**: 加权F1值约0.75-0.78

### 方法2: 高级方法 (BERT深度学习)
- **原理**: 理解评论的语义和上下文
- **优势**: 准确率更高，能理解复杂表达
- **预期准确率**: 加权F1值约0.80-0.83

## 📊 训练数据

- **数据来源**: Steam FPS游戏玩家评论
- **数据量**: 176,848条评论
- **时间跨度**: 2023年12月 - 2025年10月
- **验证方式**: 5折时间序列交叉验证

## 🎯 性能指标

### 主要指标
- **加权F1值**: 综合考虑各类别的准确率和召回率
- **宏平均F1值**: 各类别平等对待的平均表现

### 预期结果
- 基础方法: 加权F1 ≈ 0.75-0.78
- 高级方法: 加权F1 ≈ 0.80-0.83
- 高级方法比基础方法提升约5-8%

## 📈 应用场景

1. **游戏开发者**: 快速识别玩家反馈中的主要问题
2. **客服团队**: 自动分类用户投诉和建议
3. **产品经理**: 了解玩家关心的重点问题类型
4. **运营团队**: 监控游戏更新后的玩家反应

## 🔄 工作流程

1. **数据准备**: 收集Steam评论数据
2. **主题映射**: 使用LDA算法将原始8类主题重新映射为6类业务类别
3. **特征提取**: 转换评论文本为机器可读的特征
4. **模型训练**: 使用交叉验证训练和评估模型
5. **性能评估**: 计算各项准确率指标
6. **结果输出**: 生成分类报告和可视化图表

## 📁 输出文件

训练完成后会生成以下文件：
- `metrics_topic_category.json` - 详细的性能指标
- `label_mapping_topic_category.json` - 类别标签映射
- 各种性能图表和分析报告

## ⏱️ 时间估计

- **基础方法训练**: 约30分钟
- **高级方法训练**: 约5-6小时
- **总训练时间**: 约6小时

## ✅ 质量保证

- 使用时间序列交叉验证，确保模型对新数据有效
- 类别平衡优化，避免小类别被忽略
- 多指标评估，确保模型全面表现良好
